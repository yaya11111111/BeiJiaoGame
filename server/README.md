## 关键约束

- **服务端只向玩家发送当前视角需要的线索**，不能把另一视角的完整答案下发到客户端。（见需求评审第 6 章）
- 密码哈希、手机号脱敏等要求已随产品形态调整取消——本产品**不采集**真实姓名、手机号、密码，只用微信身份标识 + 玩家自设昵称。
- 密钥、secretId 等一律放 `.env`，**已在 `.gitignore` 中排除，不要提交**。
