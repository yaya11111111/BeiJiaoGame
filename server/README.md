# server — 后端服务

负责人：C

技术栈：Node.js + TypeScript。部署形态待定（微信云开发云函数 或 云托管容器）。

## 负责范围

| 能力 | 说明 | 对应需求 |
|---|---|---|
| 账号 | `wx.login` 换 openid / unionid 作为身份标识 | FR-01 |
| 用户数据 | 昵称、进度、成绩、图鉴收集 | FR-11 |
| 双人房间 | 建房 / 入房 / 退出 / 断线重连 | FR-03 |
| 消息同步 | 双人视角状态同步、文字聊天与快捷语句 | FR-04 |
| 进度存储 | 关卡解锁状态、最好用时、复玩记录 | FR-05 |
| 日志与统计 | 独立玩家数、关卡进入 / 完成数、用时、退出点 | 后台统计 |

## 接口约定

D 和 E 调用 C 提供的接口访问数据。接口文档放在本目录 `API.md`，包含接口名、入参、出参、错误码与示例。

服务端按视角返回数据，只向玩家下发当前视角需要的线索。
