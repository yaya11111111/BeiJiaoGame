# tests — 测试记录与缺陷清单

测试相关的用例、记录和缺陷都放在这里。

```
tests/
├── cases/       测试用例，按模块分文件
├── records/     每轮测试的运行记录，文件名带日期
├── bugs/        缺陷跟踪表
└── reports/     阶段性测试报告
```

## 缺陷记录字段

| 字段 | 说明 |
|---|---|
| 编号 | `BUG-001` 递增 |
| 发现时间 / 发现人 | |
| 复现步骤 | 照着做能复现 |
| 预期结果 / 实际结果 | |
| 严重级别 | 阻塞 / 严重 / 一般 / 轻微 |
| 关联需求 | 对应 FR-xx 编号 |
| 状态 | 新建 / 修复中 / 待复测 / 已关闭 |
| 修复人 / 关闭时间 | 关闭时附复测人 |

需求编号 FR-01 ~ FR-12 定义在需求评审文档第 5 章。测试用例和缺陷都对应到具体编号，用于需求→代码→测试的追溯。

## 各阶段分工

| 阶段 | 负责人 | 内容 |
|---|---|---|
| 单元测试 | 各模块负责人 | D 测关卡逻辑，C 测后端接口，E 测页面状态 |
| 集成测试 | C、D、E | 客户端与后端联调 |
| 系统测试 | 全员 | 完整走通注册 → 选模式 → 关卡 → 结算 → 地图 |
| 性能 / 非功能 | C 负责服务端，E 负责客户端 | 低端手机场景加载、双人同步延迟 |
| 验收测试 | A 组织 | 每人两台不同手机完整走 3 关 |
