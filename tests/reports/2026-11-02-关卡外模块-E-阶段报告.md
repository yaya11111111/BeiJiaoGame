### 3.2 能力补齐

- **FR-14 反馈**：设置页 + 结算页入口；截图走云存储 `feedback/`；提交调
  `feedback.submit`。云端未部署时显示失败原因并**保留草稿**，不会让玩家白写一遍。
- **FR-15 双人保存恢复（E 侧）**：双人中途退出时本地保存房间/关卡/视角/已用时/本轮
  `startedAt`；回房间页弹「继续上次的双人进度？」；继续后按原视角进入，并用
  `startedAtMs = now - elapsed*1000` 让倒计时接着走。换房、换关、房主重开、通关、
  离开房间都会自动清掉，避免拿旧进度接新一局。
- **FR-11 / FR-12 图鉴与彩蛋**：图鉴拆成「关卡成就 / 线索收藏 / 彩蛋记录」三栏；
  通关带出的线索道具（跳过 `hidden` 中间件）按 `itemId` 去重累积；`LevelReview.eggs`
  有数据时，结算页显示 `x/y + 标题`，地图节点与个人记录显示彩蛋进度；没配置彩蛋的关
  显示「本关暂未配置」，不再假装 1/1。
- **FR-12 失败结算**：失败后退出关卡进入复盘页（用时 / 原因 / 已收集线索 / 再来一次 /
  回地图；双人给「返回房间」）。失败不写通关进度、不覆盖最好用时。
- **US08 个人记录**：新增顶部导航入口；登录后拉 `auth.profile` 对照服务端
  `clearedCount` / `totalTimeMs`，失败时退回本机记录并提示。
- **适配**：`wx.onHide` 暂停房间轮询与心跳，`wx.onShow` 回前台强制补一次房间快照；
  设置页补隐私口径。
- **本地持久化**：新增 `LocalStore.ts`（微信同步存储 / 内存降级），收藏、双人进度、
  反馈回执关掉小游戏还在；`signOut` 只清账号态，不清本机图鉴。
